Diagnostic Data

When the Application crashes or encounters an error, it sends a report to Our error-monitoring providers. Reports include technical details such as the Application version, operating system, device information, and the sequence of events leading up to the error. For a sample of sessions, the Application also sends performance data, such as how long screens and operations took to load, and a replay of the session showing how You navigated and interacted with the Application. All text and images are masked in session replays before they are sent.

The Application also checks for and downloads software updates, which involves sending the Application version, platform, and a random identifier for the installation to Our update provider.
